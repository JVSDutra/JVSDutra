## Projeto em destaque

### [Bootcamp de Open Hardware](https://github.com/JVSDutra/Bootcamp_Open_Hardware)

Fork público do repositório do [FabLab Casa Firjan](https://github.com/fablabcasafirjan/Open_Hardware), com materiais de um microscópio automatizado, detector de CO₂, incubadora e turbidímetro. O conteúdo reúne listas de materiais, desenhos, sketches e imagens em níveis diferentes de documentação. A presença de arquivos não representa validação de montagem ou desempenho.

Minha contribuição documentada ao projeto upstream foi uma alteração pontual no README do detector de CO₂, no [PR #4](https://github.com/fablabcasafirjan/Open_Hardware/pull/4). O fork mantém créditos e histórico dos materiais de origem.
